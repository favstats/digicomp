# Archive

This directory contains deprecated, experimental, and historical files from earlier development iterations of the **DigIQ Monitor** project:

- **Legacy Dashboards & Prototypes**:
  - `dashboard_old.R`, `dashboard_ol2.R`, `dashboard_old2.R`, `dashboard2026.R`: Earlier iterations of the dashboard generator prior to the latest `dashboard.R` / `dashboard_en.R` architecture.
  - `run2026.R`: Previous version of the pipeline runner.
  - `app.R`, `start.R`, `rsconnect/`: Previous Shiny app prototype and deployment artifacts (May 2025).
  - `digicom.Rmd`, `digicom2.Rmd`: Flexdashboard/RMarkdown prototypes (late 2025).
  - `_site/`: Older Quarto site build output (2024–2025).

- **Early Analysis & Weighting (2024–2025)**:
  - `Exploring Wave 1 Data.R`, `weights.R`: Initial exploration and weighting scripts from May 2024.
  - `graphs.Rmd`, `graphs.html`: Exploratory graphics generation (May 2024).
  - `Recoding DigIQ - v2 Round1.Rmd`: Initial recoding script for Wave 1 (March 2025).

- **Temporary Experiments & Scratch Scripts**:
  - `minex.R`, `minex_output/`: Minimal reproducible example for modal pagination debugging (February 2026).
  - `test_green_page.R`, `test_output/`: Isolated testing script and test output directory for the Green Digital dimension (January–February 2026).
  - `dddddd.R`: Scratch script (November 2025).
  - `demo_survey_data.rds`: Sample survey dataset used for early prototyping.

- **Drafts & Documentation**:
  - `material/`: Early meeting notes, questions, and DigIQ documentation (September 2025).
  - `Overview of the DigIQ.docx`: Word overview document (March 2025).
  - `ABOUT PAGE.pdf`, `Action points dashboard.pdf`, `WAVE 1 PAGE.pdf`: Client and team notes / mockup PDFs (February 2026).
  - `about_page.md`, `wave1.md`, `pscs1.md`: Raw content notes integrated into the production dashboard and `translations.csv`.
